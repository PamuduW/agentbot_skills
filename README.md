# agent_bootstrap_skills

Personal Agent Skills compatible with the [Skills CLI](https://skills.sh/).

## Available skills

- `co-council` — structured Codex subagent exploration and Luna-tier routing.

## Local verification

```bash
npx skills add . --list
```

After this repository is pushed, install every published skill with:

```bash
npx skills add PamuduW/agent_bootstrap_skills --skill '*' -g -y
```
